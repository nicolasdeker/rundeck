## Columns

| Column | Meaning |
|---|---|
| id | stable row id (`R` main-app API route, `P` plugin API route, `W` web route / deep link, `S` service type, `BP` built-in plugin, `D` domain class, `F` file format, `B` behavior, `J` journey) |
| item | the contract item: route (`methods` `pattern` → controller.action), type, class, format, behavior or journey |
| status | `missing` (not implemented) · `partial` (implemented, oracle not fully green) · `done` (oracle/Playwright run recorded in *last run*) · `deviated` (intentional difference: ADR + `docs/COMPAT.md` line required) · `blocked` (`BLOCKED/<id>.md` + `blocked` issue required) |
| oracle spec | the upstream functional spec class(es) under `legacy/functional-test/src/test/groovy/org/rundeck/tests/functional/api/**` whose source addresses the item (route rows: literal path match, see README), the Playwright test for journeys, or `none` when no upstream test exercises it (a coverage gap: a differential test against the legacy container is then required before `done`) |
| last run | `<date> <pass>/<total> <commit> <CI url>` of the run that justifies the status; `—` until then |
| legacy reference | file:line in `legacy/` (paths relative to `legacy/rundeckapp/grails-app/controllers/rundeckapp/` for `UrlMappings.groovy`, to `legacy/rundeckapp/grails-app/controllers/rundeck/controllers/` for `*Controller.groovy`, to `legacy/rundeckapp/grails-app/services/rundeck/services/` for `*Service.groovy`, to `legacy/rundeckapp/src/main/groovy/com/dtolabs/rundeck/app/support/` for `ExecutionContext.groovy`, otherwise from the repository root) |

## Rules (MISSION.md §8)

- Never `done` without an oracle run (API) or a Playwright run (UI) recorded in *last run* on the commit being judged.
- `deviated` requires an ADR under `docs/adr/` and a line in `docs/COMPAT.md`; `blocked` requires `BLOCKED/<id>.md` and a `blocked` issue.
- Unimplemented endpoints answer `501` with the legacy error envelope (`api.error.not-implemented`) and stay `missing`.
- Oracle specs are never edited or skipped to turn a row green; a legacy-specific or wrong test goes to `tests/parity-skips.toml` and the row stays `deviated`/`blocked`.
- `V` stands for `$api_version` (14–60); route patterns are quoted verbatim from `UrlMappings.groovy` (Grails syntax: `$x` one segment, `$x?` optional, `$x**` rest of path, `(.$format)?` optional extension).
